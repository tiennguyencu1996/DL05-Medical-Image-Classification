# DL05 - Medical Image Classification

## 1. Project Overview

**Topic:** Medical Image Classification:
A CNN Designed from Scratch versus Transfer Learning.

- Course: Deep Learning Fundamentals
- Topic Code: DL-05
- Institution: Phenikaa University
- Framework: TensorFlow / Keras

## 2. Project Objectives

1. Design and implement a CNN from scratch.
2. Implement a transfer learning model.
3. Compare both approaches using the same data split.
4. Evaluate class-imbalanced medical image classification.
5. Analyze label efficiency at 10%, 25%, 50%, and 100%.

## 3. Evaluation Metrics

- AUROC
- Sensitivity
- Specificity
- Macro-F1
- Confusion Matrix

## 4. Technology Stack

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
